# Growblic: The Design Package

Tier 1, The Digital Bloom. Written before generation, consumed by the build. Every viewer-facing line below ships verbatim.

## 1. The brand premise

Growth. Growblic's name, mark, and business all say one thing: software is something you grow. An idea is planted, engineered into a product, and then grown into a business with the same hands that built it. The site teaches and sells that one idea. Every section either grows something (the hero, the vine, the process) or proves the growth is real (35+ live apps, promises, FAQ). One call to action: Start your project.

## 7. The vector layer plan

- **The signature: the circuit-vine.** One continuous SVG path drawn down the entire below-fold page, self-drawing with scroll (stroke-dashoffset), branching a short filament into each section as it arrives. Jade at whisper level (--accent-muted). If removed the page loses its spine, which is what a signature means.
- **The environment layer.** One fixed background behind everything: near-invisible drifting jade motes (CSS, 3 to 5 elements) and a soft radial grade, cycling at 70s. Pauses off-screen and on hidden tabs.
- **The mark.** Growblic's leaf mark recreated as inline SVG for favicon and nav (white, crisp at any size), traced from the downloaded original.
- One living element per section at whisper level (a slow glow pulse on the section's branch node, 5s or longer, negative delay).
- All of it honors reduced motion: final states shown, drives stopped.

## 8. The engineering list

The full standard from scrub-pipeline.md, all of it: Blob fetch with streamed loading ring (video will exceed 8 MB budget assumption until measured), dt-normalized lerp that rests, gated seeks with the deadlock escape, delta-gated DOM writes, band pacing with the flick test, the four-layer legibility system with the worst-frame audit at 3.5:1, the five static-hero gates identical in CSS and JS with live change listeners, complete-without-video, overflow-x clip on html and body, reduced motion honored live in both directions, and the quality floor. Plus the whole-site-animated standard: entrances choreographed per section, retirement of stagger delays proven, transform and opacity only.

Stack deviation, said out loud: this build ships as a Next.js 16 app in Docker, not a bare HTML folder. The hero engine is still plain vanilla logic inside one client component; no animation libraries.
